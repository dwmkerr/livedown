— how it works
1. CLI + Watcher
Node · tweetnacl
Reads your file. Generates an Ed25519 keypair. Signs every push with the private key. Re-verifies every incoming update before writing to disk.
2. Stateful Relay
Cloudflare Workers · PartyKit · @noble/curves
One WebSocket room per document. Holds the public key in memory, verifies signatures, broadcasts verified updates. Rooms evaporate when the last client drops.
3. Browser Viewer
Vanilla JS · tweetnacl
Renders the markdown live, unlocks editing when an edit key matching the room's public key is entered. Pushes are signed in-browser before hitting the wire.
— security
Three layers
of verification.
Livedown writes remote content straight to your disk, so every update is signed with Ed25519 and checked independently by the relay, the watcher, and the browser. A compromised relay still can't forge an edit your watcher will accept.
